# К-ТЕЛЕКОМ
## Система мониторинга состояния сетевой инфраструктуры

Версия: 1.0  
Платформа: Windows 10/11 (64-bit)  
Язык программирования: C++17  
Фреймворк: Qt 6.12  

---

### 1. О ПРОЕКТЕ

«К-Телеком» — настольное приложение для визуального мониторинга состояния сетевой инфраструктуры.

Программа предназначена для демонстрации принципов сбора, обработки, анализа и визуализации сетевых показателей. Она объединяет инструменты наблюдения за состоянием маршрутизаторов, анализа телеметрии, отображения географического расположения узлов и регистрации событий.

Интерфейс построен по принципу единой панели управления, позволяющей получать общую информацию о состоянии сети и переходить к отдельным разделам системы.

### 2. ОСНОВНЫЕ ВОЗМОЖНОСТИ

**Панель мониторинга**
- Отображение сводной информации о состоянии сети.
- Вывод основных показателей производительности.
- Отслеживание количества устройств с различными статусами.

**Мониторинг маршрутизаторов**
- Просмотр списка сетевых устройств.
- Отображение параметров телеметрии.
- Определение текущего состояния каждого маршрутизатора.
- Хранение истории измерений во время работы приложения.

**Аналитика**
- Визуализация изменения сетевых показателей.
- Построение графиков на основе полученной телеметрии.
- Анализ динамики параметров сети.

**Географическая карта**
- Отображение сетевых узлов на интерактивной карте.
- Использование картографической библиотеки Leaflet.
- Получение картографических данных из OpenStreetMap.

**Система уведомлений**
- Автоматическое обнаружение изменений состояния устройств.
- Вывод всплывающих уведомлений.
- Звуковое оповещение о критических событиях.
- Разделение событий по уровням серьёзности.

**Отчёты**
- Регистрация обнаруженных событий.
- Отображение истории уведомлений в виде таблицы.
- Просмотр информации о проблемных устройствах.

### 3. АРХИТЕКТУРА ПРОЕКТА

Приложение построено с использованием объектно-ориентированного подхода. Основные компоненты разделены по назначению.

Основные классы и модули:

- **Router** — модель сетевого маршрутизатора и его состояния.
- **Measurement** — структура хранения результатов сетевых измерений.
- **NetworkAnalyzer** — анализ показателей и определение состояния устройств.
- **GarchProcess** — генерация случайных процессов на основе модели GARCH(1,1).
- **TelemetryGenerator** — формирование демонстрационных показателей телеметрии.
- **ScenarioController** — управление сценариями изменения состояния сети.
- **NetworkManager** — централизованное управление маршрутизаторами и обновлением данных.
- **NetworkChart** — построение графиков сетевых показателей.
- **Alert** — модель события или уведомления.
- **AlertManager** — обнаружение изменений состояния и управление событиями.
- **AlertNotification** — отображение всплывающих уведомлений.
- **MainWindow** — главное окно приложения и управление пользовательским интерфейсом.

### 5. УСТАНОВКА И ЗАПУСК

**Готовая сборка для Windows**

1. Скачайте архив KTelecom-Windows.zip из раздела Artifacts соответствующего запуска GitHub Actions.
2. Распакуйте архив в отдельную папку.
3. Запустите KTelecom1.exe.

Важно: не перемещайте исполняемый файл отдельно от остальных файлов поставки — они содержат необходимые библиотеки и ресурсы Qt.

**Сборка из исходного кода**

Для самостоятельной сборки потребуются:
- Qt 6.12 с компонентами Widgets и WebEngineWidgets.
- CMake.
- Компилятор C++17 (MSVC 2022 для Windows).
- Git (для получения исходного кода).

Основные команды:

    git clone https://github.com/milka-pilka/KTelecom.git
    cd KTelecom

    cmake -S . -B build
    cmake --build build --config Release

Для корректной конфигурации CMake необходимо указать путь к установленному Qt.

### 6. ОСОБЕННОСТИ И ОГРАНИЧЕНИЯ

Текущая версия приложения является демонстрационной.

- Сетевые показатели генерируются программно и не получаются от реального сетевого оборудования.
- Сценарии изменения состояния маршрутизаторов используются для демонстрации работы системы мониторинга.
- Географические координаты являются демонстрационными и не обозначают фактическое расположение оборудования К-Телеком.
- История уведомлений и измерений хранится в оперативной памяти и очищается после завершения работы приложения.
- Для загрузки картографических данных требуется подключение к Интернету.
